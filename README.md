# MFC를 이용한 보드 게임
>동의대학교 23학년도 2학기  비쥬얼 프로그래밍 교과목의 팀 프로젝트 "MFC를 이용한 보드 게임"을 위한 레포지토리입니다.

## 주요 기능
  - 멀티 플레이 보드게임: MFC(Microsoft Foundation Class)와 소켓 통신을 활용하여 개발된 멀티플레이어 보드게임
  - 직관적인 UI: MFC를 이용해 직관적이고 사용자 친화적인 그래픽 사용자 인터페이스(GUI)를 구현
  - 네트워크 기반 플레이: 로컬 네트워크나 인터넷을 통해 친구와 함께 게임을 즐길 수 있도록 소켓 통신을 기반으로 설계

## 개발 환경
  - **IDE**: ~~Visual Studio 2019~~ -> Visual Studio 2022
  - 추가적인 MFC 개발 구성 요소 필요
